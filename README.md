# 🧠 IA Chat Microservice - BackEnd

This microservice serves as an interface between your **frontend** and **OpenAI's GPT model**.
It receives user messages via an HTTP POST request and returns AI-generated responses.
No database is required — all configuration (such as the OpenAI API key) is managed through a `.env` file

---

## 🚀 How It Works

The service exposes a single `/chat` route that receives a user's message and returns a response generated by the OpenAI language model.

It responds with a **success** and the AI-generated reply, or a **failure** message if the request to OpenAI fails.

---

## 📦 Installation & Launch

### Clone the project

    >   git clone <repo-url>

### Navigate to the project folder

    >   cd project-folder-name

### Install dependencies

    >   npm install

### Add environment variables

Create a `.env` file at the root of the project with the following content :

```
PORT=port
OPENAI_API_KEY=...

```

### Run tests

    >   npm test

### Start the server

    >   npm start

---

## 📡 Available Route

### POST /chat

- **URL :** `http://localhost:port/chat`.
- **BODY (JSON) :**

```
{
  "message": "Type a message..."
}
```
